# 演出デモ（HTMLプロトタイプ）

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要、外部ライブラリなし）。

- **効果音**：25本を `sounds.js` に内蔵しています。開くと自動で読み込まれ、すぐに鳴ります。
- **画像**：リポジトリには入っていません。ページにドラッグ＆ドロップするか「画像を読み込む」で指定してください。
- 追加の音声もドロップで足せます。読み込んだファイルはブラウザ内でのみ使われ、外部には送信されません。

## 内蔵効果音

- 「ヒット音：自動」では、1打だけの音声（「1回だけ〜」の2本）からランダムに鳴らします。
  一定リズム・不規則リズム・加速の各プリセットはこの音で鳴ります。
- 音声同期（7・8）では、複数打撃の音声をそのまま再生し、打撃位置で演出を出します。
- 音声を差し替える・増やすときは、フォルダにまとめて次を実行してください（ffmpeg が必要）。

  ```sh
  python3 tools/build_sounds.py <音声フォルダ>   # → sounds.js を上書き
  ```

  `file://` で直接開いても読み込めるよう、MP3 を base64 にして `<script>` で読む形式にしています。

## プリセット

| キー | プリセット | 内容 |
|---|---|---|
| 1 | 単発インパクト | 1発だけ強めのヒット |
| 2 | 3連打 | 0.42秒間隔で徐々に強く |
| 3 | 一定リズム | BPMスライダーの速さでループ（再生中も変更可） |
| 4 | 不規則リズム | 間隔（素早い2連／通常／ため）と強弱をランダムに |
| 5 | 加速→クライマックス | BPM 70→210 に加速 → 白飛び・強振動・ハート・寄り → 余韻へ |
| 6 | 余韻 | 呼吸・湯気・鼓動・ピンクのビネット |
| 7 | 音声同期（1本） | 選択中の音声を再生し、検出した打撃位置でヒット演出 |
| 8 | 音声同期（連続） | 複数打撃の音声をランダムに切れ目なく繋げて同期 |

`Space` 手動ヒット ／ `Esc` 停止 ／ `H` HUD ／ `F` 全画面 ／ ステージをクリックで演出の中心点を指定

## 演出の構成

**ヒット演出（1打ごと、個別にON/OFF）**
揺れ（縦・横・前後）、ズームパンチ、画面振動、フラッシュ、波紋、ズームブラー、集中線、擬音テキスト、飛沫、ハート

**常時演出**
呼吸、湯気、汗のきらめき、浮遊ハート、ビネット、鼓動

**HEAT（興奮度 0〜100%）**
ヒットごとに上がり、時間で下がります。ビネットの濃さ、湯気の量、呼吸と鼓動の速さに反映されます。

**差分切替**
画像を2枚以上読み込むとサムネイルのクリックでクロスフェード切替。クライマックス時は最後の画像へ自動で切り替わります。

## 音声同期の仕組み

1. 音声を 5ms 刻みの RMS エンベロープにする（`analyze()`）
2. 「最大値に対する絶対しきい値」と「直前200msの平均に対する立ち上がり比」を両方超えた瞬間を打撃とみなす（`detect()`）
3. 打撃の音量から演出の強さを決める（`0.35 + 0.8 * √音量`）

「検出感度」スライダーで両しきい値を調整できます。検出位置は波形上のピンクの線で確認できます。
演出の発火は `AudioContext.currentTime` を基準に先読みスケジュールしているため、フレームレートに関係なく音とずれません。

## Unity へ移植する場合の対応

| HTML側 | 内容 | Unityでの置き換え例 |
|---|---|---|
| `Spring` | 減衰バネ。`kick()` で速度を加える | 同じ式を `Update` で計算（`k`=硬さ, `ζ`=減衰比） |
| `cam.trauma` | 振動量。表示は trauma² × ノイズ。毎秒1.5ずつ減衰 | `Mathf.PerlinNoise` でオフセット／回転 |
| `hit(strength)` | 1打の演出をまとめて発火 | 同名のメソッド1つにまとめると扱いやすい |
| `climax()` | 白飛び＋最大振動0.5秒維持＋寄り＋パーティクル | Timeline か コルーチン |
| `Conductor` | 音声時計で先読みスケジュール | `AudioSettings.dspTime` ＋ `AudioSource.PlayScheduled` |
| `analyze()` / `detect()` | 打撃位置の検出 | 実行時に解析するか、エディタで事前計算してタイミングを保存 |

主なパラメータ（強さ 1.0 のとき）：

- 揺れ：初速 380px/s、バネ硬さ 260、減衰比 0.28〜0.85（「揺れの柔らかさ」）
- ズームパンチ：拡大率の初速 +0.55/s
- 振動：1打で trauma +0.3、最大オフセット 34px、最大回転 0.025rad
- フラッシュ：不透明度 22% → 約0.15秒で消える
- 基本拡大率 1.08（揺れても画面端が見えないように）
